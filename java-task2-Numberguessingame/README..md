About the Project

This is a simple Java console application that I created to practice Java programming concepts. In this game, the computer randomly selects a number, and the player has to guess it. After every guess, the program tells the player whether the guessed number is too high or too low until the correct number is found.

Features
Random number generation
User-friendly console interface
Hints after every guess
Counts the number of attempts
Simple and easy to understand code
Technologies Used
Java
Scanner Class
Random Class
How to Run
Clone this repository.
Open the project in your favorite Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
Compile and run the NumberGuessingGame.java file.
Start guessing the number!
