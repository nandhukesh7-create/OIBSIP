About the Project

This project is a simple ATM simulation developed using Java. The application allows users to perform basic banking operations such as checking their account balance, depositing money, and withdrawing money after entering the correct PIN.

The main goal of this project was to understand Object-Oriented Programming concepts and create a menu-driven console application.

Features
Secure PIN verification
Check account balance
Deposit money
Withdraw money
Menu-driven interface
Basic input validation
Technologies Used
Java
Object-Oriented Programming (OOP)
Scanner Class
How to Run
Clone this repository.
Open the project in your preferred Java IDE.
Compile and run the ATMInterface.java file.
Enter the correct PIN to access the ATM menu.
